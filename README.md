# Employee Management System

A Full Stack Employee Management System built using modern enterprise technologies.

## Tech Stack

### Backend
- Java 21
- Spring Boot 4
- Spring Data JPA
- Spring Security (Upcoming)
- Maven

### Frontend
- Angular 21

### Database
- PostgreSQL 18

### Tools
- Git
- GitHub
- Postman
- STS 4
- VS Code

## Features

- Employee Management
- Department Management
- JWT Authentication
- Role Based Authorization
- Validation
- Global Exception Handling
- Swagger Documentation
- Angular Dashboard

## Project Status

🚧 Currently under development.

This project is being developed step-by-step to understand Spring Boot and Angular from scratch.
