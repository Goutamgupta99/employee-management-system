# Employee Management System

A Full Stack Employee Management System built using Java, Spring Boot, Angular, and PostgreSQL following a layered architecture and enterprise development practices.

---

## 🚀 Tech Stack

### Backend
- Java 21
- Spring Boot 3.5.x
- Spring Data JPA (Hibernate)
- Spring Validation
- Maven

### Frontend
- Angular 21 (Upcoming)

### Database
- PostgreSQL 18

### Tools
- Spring Tool Suite (STS) 4
- Visual Studio Code
- Postman
- Git
- GitHub

## ▶️ Running the Project

1. Clone the repository

```
git clone https://github.com/Goutamgupta99/employee-management-system.git
```

2. Configure PostgreSQL credentials in

```
src/main/resources/application.properties
```

3. Run the application

```
mvn spring-boot:run
```

4. Test API

```
POST http://localhost:8080/api/employees
```
